# 📘 今日AI问答（2026-09-09）

**【问题】** 什么叫"API"？

**【回答】**

API（应用程序编程接口）说白了就是两套软件之间的"点菜窗口"：你不用知道对方厨房里怎么炒菜，只要按菜单格式递需求，就能拿到结果。

打个物流行业的比方：客户给快运公司下单发件，并不需要知道你们内部怎么调度车辆、分拣、交接——只要按运单格式把收发件人、重量填清楚，剩下的流程系统自己跑完。这张运单，就是客户和你们业务系统之间的"接口"。

软件世界一模一样：当你用iMa、GLM AgentMore"问问"大模型时，背后就是通过API把你的问题按固定格式递到模型的窗口，模型再把答案递回来。而你常听到的"API key"，就是这张窗口的工牌——证明你有资格点菜，系统好按调用次数计费。所以API key要像密码一样保管：谁捡到谁就能冒充你点菜，费用记你账上。

**【延伸一句】** 大模型公司宣布"开放API"，就是对外开放自家模型的点菜窗口——Codex能接入自定义模型、各家工具能互相打通，靠的都是它。
